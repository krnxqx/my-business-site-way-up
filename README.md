# WayUp — сайт бізнес-ідеї

Багатосторінковий сайт платформи планування індивідуальних маршрутів Україною.

## Структура
- `index.html` — головна
- `how.html` — як працює
- `routes.html` — приклади маршрутів
- `pricing.html` — тарифи
- `contact.html` — контакти + форма
- `style.css` — стилі
- `script.js` — перемикач мови UA/EN + форма

## Як розмістити на GitHub Pages

1. Зайдіть у свій акаунт GitHub: **krnxqx**
2. Натисніть **New repository**
3. Назва: `wayup-site` (або будь-яка інша)
4. Оберіть **Public**
5. Натисніть **Create repository**
6. Натисніть **Add file → Upload files**
7. Перетягніть усі файли з цієї папки (index.html, how.html, routes.html, pricing.html, contact.html, style.css, script.js)
8. Натисніть **Commit changes**
9. Перейдіть у **Settings → Pages**
10. Source: **Deploy from a branch**
11. Branch: **main**, Folder: **/ (root)**
12. Save

Через 1–2 хвилини сайт буде доступний за адресою:

**https://krnxqx.github.io/wayup-site/**

(якщо назва репозиторію інша — підставте її)
